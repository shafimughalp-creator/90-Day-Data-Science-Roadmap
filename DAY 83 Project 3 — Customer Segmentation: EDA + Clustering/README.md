# Data for Day 84

The Mall Customers file is **not included** in this folder.

## File needed
- `Mall_Customers.csv` (200 rows, 5 columns: CustomerID, Genre or Gender, Age, Annual Income (k$), Spending Score (1-100))

## How to get it
1. **From Kaggle:** search for the "Customer Segmentation Tutorial in Python" dataset (by Vijay Choudhary) at
   https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python
   You need a free Kaggle account. Put `Mall_Customers.csv` in this `data/` folder.
2. **Or just run the notebook.** If the file is missing from `data/`, the notebook downloads a public copy from GitHub
   (the `BASE` link in `segmentation_data.py`). This needs an internet connection.

## Notes
- It is a small, public teaching dataset. The "Spending Score" is a score the mall assigned, not money spent.
- Check the dataset page for its terms before sharing the file yourself. That is why the raw file is not part of this folder.
