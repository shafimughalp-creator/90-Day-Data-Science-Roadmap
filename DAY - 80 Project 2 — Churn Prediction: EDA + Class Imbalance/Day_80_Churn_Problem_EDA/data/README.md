# Data for Day 80

The Telco Customer Churn file is **not included** in this folder.

## File needed
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` (the Kaggle name) or `Telco-Customer-Churn.csv` (7,043 rows, 21 columns)

## How to get it
1. **From Kaggle:** search for the "Telco Customer Churn" dataset (by BlastChar) at https://www.kaggle.com/datasets/blastchar/telco-customer-churn
   You need a free Kaggle account. Put the CSV in this `data/` folder.
2. **Or just run the notebook.** If the file is missing from `data/`, the notebook downloads a public copy from GitHub
   (the `BASE` link in the loading cell). This needs an internet connection.

## Note on sharing
This is a sample dataset published by others. Check the dataset page for its terms before sharing the file yourself.
That is why the raw file is not part of this folder.
